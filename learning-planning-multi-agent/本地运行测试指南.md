## 📊 评价与反馈数据结构

### 反馈记录 (`feedback_records.json`)

```json
{
  "id": "uuid",
  "resource_id": "xxx",
  "resource_title": "资源标题",
  "resource_url": "https://...",
  "feedback_type": "useful",
  "rating": 5,
  "comment": "用户评论",
  "learning_objective": "学习目标",
  "created_at": "2026-05-30T..."
}
```

**feedback_type 取值**:
- `useful` - 资源有用（好评）
- `not_useful` - 资源没用（差评）
- `add_new` - 提交新资源

### 自动入库规则

- 同一资源收到 **≥2 个** `useful` 反馈
- 且平均评分 **≥4 分**
- 自动加入向量数据库

## 🔧 常见问题

| 问题 | 解决方法 |
|------|---------|
| 网络搜索受限 | 配置 `TAVILY_API_KEY` |
| LLM调用失败 | 检查 `DEEPSEEK_API_KEY` 是否有效 |
| 向量数据库加载慢 | 首次运行会下载 embedding 模型（约79MB） |
| 前端无法连接后端 | 确认后端运行在 8000 端口，前端API地址配置正确 |
| DeprecationWarning: on_event | 已修复，使用 lifespan 事件处理方式 |

## 🤖 多智能体工作流

```
用户输入
    │
    ▼
┌───────────────┐
│ 需求分析Agent │ ← 关键词提取 + LLM提取
└───────┬───────┘
        │
        ▼
┌───────────────┐
│ 课程规划Agent │ ← 根据时间期望生成阶段
└───────┬───────┘
        │
        ▼
     ┌──┴──┐
     │     │
     ▼     ▼
┌─────────┐ ┌─────────────┐
│资源推荐 │ │ 评估反馈Agent │
│Agent    │ │             │
└────┬────┘ └──────┬──────┘
     │             │
     └──────┬──────┘
            │
            ▼
     结果整合返回
```

### Agentic RAG 工作流

```
1. 构建检索查询
        │
        ▼
2. 检索知识库 (Chroma)
        │
        ▼
3. 评估结果:
   ├─ 相似度 ≥ 0.5 → 直接推荐
   ├─ 相似度 < 0.5 且 改写次数 < 2 → 改写查询，回到步骤1
   └─ 无结果 或 已达最大改写次数 → 网络搜索
        │
        ▼
4. 网络搜索 (Tavily)
        │
        ▼
5. 合并结果并返回
```
