# 只是被破坏的不是 ragas，而是 langchain 0.3.x 的声明一致性。
#
# 评测脚本（evaluate_ragas.py）只 import 检索链路（vector_store），不需要 fastapi / langgraph，

#
# 本文件经 `pip install --dry-run` 解析通过（core 0.3.86 组合无冲突）。
